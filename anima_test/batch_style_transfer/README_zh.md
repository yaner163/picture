# 批量角色 → 画风转换（管线已跑通，pilot 质量）

时间：2026-11-03 20:00–20:07
目的：验证“网上找大批量角色图 → 转成参考画风”这条链路，而不是只做单个测试。

## 图源

- **Safebooru**：本机可直连，API 返回 700 万+ 动漫图，带 tag（`solo 1girl highres` 等可精确筛选）。
  - API：`https://safebooru.org/index.php?page=dapi&s=post&q=index&json=1&limit=..&tags=..`
  - 下载：`file_url` 直链，实测可下（含 3000px 级原图）。
- 不可用：pixiv、Danbooru、konachan、yande.re、gelbooru（本机连接超时）；HF 时通时断。

## 管线（两步）

1. **取图**：按 tag 搜 Safebooru → 过滤分辨率（<900px 跳过）、排除 comic/多视图 → 下载原图。
   脚本：`_work/batch_style_transfer.py`
2. **转画风**：对每张图做 img2img：
   - 居中裁成 2:3 → 768×1152；
   - 原图经 Qwen-Image VAE 编码 → latent；
   - 用 Base v1.0 + pilot style LoRA（strength 1.0），30 步、CFG 4、euler/simple、denoise 0.6 重绘；
   - 解码保存；提示词 = 画风触发词 `r04style` + 画风描述 + 源图 tag 转成的自然语言。
   脚本：`_work/batch_style_transfer.py`（内含 img2img；单张版 `_work/style_transfer_img2img.py`）

## 实测结果

- 6 个不同角色（不同发色、服装、构图、原画师风格）全部转换成功。
- 单张耗时约 **46–50 秒**（768×1152、30 步、denoise 0.6）；6 张共约 5 分钟。
- 转换方向一致：脸型柔化、眼睛放大、皮肤过渡更绘画化、暗背景布光更明显——也就是把不同作者的角色往同一画风上拉。
- 见 `对比图_批量转换_源图与风格化.png`（上排源图、下排风格化）。

## 重要限制（必须先说清）

1. **当前是 pilot LoRA（18 张切图）**，转换是“半成品级”：能看出风格方向，但厚涂笔触、布料分组、细节还不到位。**要真正达到参考图水准，得先训出 v1 画风 LoRA（60–120 张该画师作品）**，再用这个批量管线才是可用的量产质量。
2. **成本**：单张约 46 秒，100 张约 1.3 小时，可后台批跑；显存峰值约 13.5 GiB（动态显存溢出到共享内存，未 OOM）。
3. **版权**：Safebooru 上是其他作者的角色，转成某画师画风属于衍生创作。内部风格研究/预览可以；**不能直接当游戏资产发行**，商业使用需权利或改用自己的原创角色。
4. **不要自动回流训练**：把这些转换图直接当训练数据会形成“自己教自己”的循环，越训越偏；如要用于数据增强，必须人工筛选 + 与真实画师作品混合，并保留原始风格图占主导。

## 下一步（按目标排序）

1. **先拿真实画风数据训 v1**（最优）：该画师的不同角色作品 60–120 张。若你知道画师名字/P站 ID，我可以尝试从 Safebooru 的 `artist:` tag 直接拉其作品；或你给 pixiv 访问方式。
2. **v1 出来后再批量转**：那时同样的管线可以把任意角色批量转成“这个画风”，质量会明显高于现在。
3. 如你只是先看效果/选方向：现在这 6 张就是预览；告诉我目标数量（如 50/100/500 张）和用途，我按批次跑。
